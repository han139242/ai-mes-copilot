# 阶段 2 复核与界面优化

复核日期：2026-11-08。依据为维护者提供的《阶段2任务.pdf》四张课件、补充图片及本地当前源码。保留原业务、独立运行数据、米白天蓝配色和模型请求累计上限；本轮没有公开发布。

## 本轮落实的调整

用户实际截图暴露了重复标题、欢迎语和输入框争夺空间的问题。本轮将页面按资料管理、问答、来源和图谱组织，不再依靠大标题表现功能。

- 顶部保留紧凑页签与操作，资料问答的标题和可用数量合并为一行。
- 左侧使用米白资料区，版本/文件类型与处理状态分层，去除重复显示的文档就绪状态；搜索、下载、更新和删除仍在原入口。
- 空会话改为简短提问引导，提供“整理操作步骤”和“追查资料关联”两个真实示例。点击只填入草稿，保留原问题，不自动发送。
- 输入区使用常用高度和有限阅读宽度，保留四种模式、字数、发送、停止和处理范围说明；手机及短窗口保持输入和发送可见。
- 资料更新、处理失败、旧版沿用、引用失效及无匹配结果的提示保留，不用样式掩盖状态。
- 发现自由探索图会把节点裁在画布边缘，增加首次适配和“适应窗口”。之后的筛选、选中和资料刷新仍保留用户镜头；“还原视图”继续清除筛选并恢复 100% 缩放。

图谱只调整视图，不修改节点、关系或来源，不新增建图和模型请求。图谱关联路径、键盘文字列表、来源预览、原业务助手与快捷办理继续保留。
