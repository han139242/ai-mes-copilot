# 前端体验精修与参考记录

本轮跨 2026-11-10 至 2026-11-11，重点改善共用业务页面、全局导航与未保存内容的保护。视觉继续采用米白画布、暖白操作面和克制的天蓝色，参考范围包括 Claude 生成的页面、Claude 与 Codex 产品，以及成熟企业软件的交互规范。

## 本轮改进

### 工作空间与导航

- 桌面页签并入 64px 顶栏，内容起点从原来的 108px 提前至 64px。窄屏分成两行。
- 同一个页签组件随屏幕宽度移动，跨 1120px 断点时保留正在进行的关闭操作。取消离页时，页签、地址、页面内容和标题保持一致。
- 模块导航支持中文名称、英文路径、近期访问、上下键和 Enter。中文输入法确认文字时保留当前输入。
- 近期导航只记录当前账号可访问的模块路径，业务查询参数、提问和单据编号不进入该记录。

### 业务列表与查询

- 短列表按内容收缩，长列表在表内滚动。BOM 六行主表实测高度从约 633.6px 缩至 322.4px。
- 点选记录后才展开关联明细，折叠后保留选中状态。批量操作随选择出现。
- 区分编辑中的条件和已查到的结果。请求失败保留上一份结果、明确状态，并暂时禁用基于旧结果的写操作与导出。
- 空结果可清除条件恢复，首屏读取前显示真实的等待状态。乱序请求、较晚返回的详情和已经离开的页面都有失效检查。
- 手机分页将每页大小、任意跳页放在第一行，上一页、页位置、下一页放在第二行。桌面继续提供数字页码。

### 关联名称

真实检查发现，关联选项仅加载最新 200 条时，旧 BOM 的产品 ID 1～6 无法匹配名称。本轮按当前记录需要的 ID 补读详情，保留名称和用于区分的编码。

- 每类补读最多同时进行 6 个请求，共用同一条记录的在途读取。
- 切换查询、离开页面或身份变化后，停止后续批次并丢弃旧回填。
- 打开业务动作、刷新选项时合并已解析的旧记录，避免名称再次丢失。
- 未取得名称时明确展示对象类型、编号与状态，并在权限允许时提供重读入口。

### 表单与工作单

- 手工字段修改、子表增删、报工重新带料及上传元数据都参与草稿判断。自动初始化保持可直接取消。
- 关闭、Esc、离页、浏览器返回和页面刷新都会保护草稿。退出或身份失效时清理内存中的私有草稿。
- 在校验和远程预检查开始前锁定整次提交，防止连续点击留下延迟重复请求。保存失败保留输入，成功后正常离开。
- 研判工作单补齐页签刷新保护，保留原有来源核查、交接导出与转业务草稿入口。

## 2026-11-11 逐模块精修追加

维护者要求逐个部分优化，并在后台完成操作。本批先处理 AI 工作台，再处理私有知识问答。沿用米白与天蓝、现有 Vue / Element Plus、权限目录及业务预览流程。

### AI 工作台与浮窗

- 快捷办理可以搜索名称、说明和业务阶段，搜索清除后恢复当前账号全部21个入口。会话记录单独切换，草稿会话也能找到。
- 欢迎区常驻当前任务和两个可回填问题，其他能力与示例按需展开。7种能力及原有业务表单继续可用。
- 尚未发送的问题按会话保留在内存中，切换会话、工作台/浮窗、离开后返回及组件刷新均可继续编辑。浏览器整页刷新或关闭前有未发送提醒，重新打开浏览器时需要重新输入。
- 示例覆盖手写输入后可以撤销。重试和重新生成保留正在编辑的下一问，生成期间可继续编辑。
- 清空、删除和归档先等远端结果，再更新本地。真实错误可见，确认取消保持安静；历史修改与发送相互排斥，身份变化后旧请求不能回填或释放新请求状态。
- 首次取得远端会话编号后继续使用稳定的本地标识。后续同步保留草稿及撤销，较早的未发送会话也会保留。
- 手机抽屉的关闭控件与标题错开，新建与发送为44px。输入组件随容器宽度重新计算行高，390px已有草稿从32px裁切修至56px完整显示，长输入最多五行滚动。
- Ctrl+K按实际可见状态开关浮窗。从浮窗进入工作台时会选中完整工作台形态，可以直接看到待确认卡片。

### 私有知识问答

- 推荐问题和图谱线索回填后，可以撤销并恢复原问题与检索方式。1000字符边界使用原有UTF-16安全截断。
- 新建空会话后可以返回上一会话，恢复消息、问题、检索方式及原回填撤销。开始编辑新问题后，返回入口收起，保护当前输入。
- 返回时比较资料版本及答案发布代次，旧回答会标为失效。清除历史和身份切换清理旧返回快照。
- 失败问题重试保留正在编辑的下一问。清除历史保留当前输入和撤销，等待期间暂停新问答，较晚返回的历史读取会失效。
- 资料搜索无结果时可以直接清除搜索。空计数收起，发送按钮在空输入和输入文字后保持右侧对齐。

知识会话的返回与撤销属于当前页面的内存状态。离开或整页重新加载知识页后，该状态会结束。已保存的历史仍通过原接口读取。
