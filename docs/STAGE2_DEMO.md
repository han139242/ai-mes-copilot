# 阶段 2 演示与收尾

本页对应教师的设计、实现、核心代码、功能展示、分析及问题解决要求。它是可复现演示步骤，不替代真实课堂展示或打卡。当前未完成的真人认证和分工确认须如实补齐。

## 演示前

1. 按 [服务说明](../services/private-assistant/README.md)启动新版，核对前端、后端、私有服务与专用数据库。
2. 只使用 `examples/lamp-demo` 及离线脚本生成的合成资料，说明它们不是行业标准。
3. 确认本人模型处理同意和平台额度。当前默认无本地次数上限，调用仍记录；现场主动问答或建图会消耗平台额度。只做离线展示时关闭模型处理，使用本地检索、已有答复和图谱。
4. 准备两个已有 AI 权限的演示账号，分别登录。原受限角色应继续被拒绝，不能为演示临时移除权限检查。
5. 真人演示由账号本人完成摄像头许可与录入；不在公开截图中留下人脸、密码、密钥或个人资料。

## 建议顺序

| 步骤 | 操作 | 展示与核对 |
|---|---|---|
| 1 | 原 MES 登录，打开原 AI 工作台 | 左侧快捷办理、业务模块及预览确认仍在 |
| 2 | 打开“我的知识” | 本人资料、真实状态、历史、四种模式可见 |
| 3 | 另一账号打开同一入口 | 私有文件与历史不同；不能拿第一账号的文件 ID 下载 |
| 4 | 上传 Word、Excel 或 PDF 示例 | 任务开始，本地向量就绪；对应段落/单元格/页码可打开 |
| 5 | 问 L100 的驱动板或检验码 | 回答带有效引用，点击可核对原文版本和定位 |
| 6 | 选择图谱/融合，问跨文件关系 | 实际使用关系与原文，不能只展示模式标签 |
| 7 | 图谱搜索 L100、展开相邻两跳 | 产品、物料、工序、规范及边来源可查看；文字列表可操作 |
| 8 | 更新资料，再删除临时资料 | 新版发布前保留旧版；删除后旧事实不继续进入新问答 |
| 9 | 改岗位/熟悉程度/篇幅偏好 | 表达按偏好变化，业务权限不变；以保存的真实样例对照 |
| 10 | 提出实时库存/工单请求并转业务助手 | 原问题进入草稿，不自动发送或执行；办理仍须人工确认 |
| 11 | 本人人脸录入、退出、用人脸重登 | 未同意不采集；实际特征存储与原 JWT 登录衔接 |
| 12 | 错误脸、过期挑战、重录/解绑或管理员重置 | 给出明确拒绝/恢复结果；密码入口始终可用 |

离线演示可使用保存的真实答复及当前原文/图谱核对，不将回放冒充现场新生成。更新/删除可在关闭模型处理后演示本地索引；演示前记录原设置，结束后由本人决定是否恢复。

## 编排探索

现有 MES 已有多步办理、任务状态、预警与异常闭环。本轮把“资料依据 → 原业务助手草稿 → 原预览确认”连接起来，知识服务本身没有业务写入口。

可继续探索的质量核查流程为：取得有权限的当前质量异常 → 选择本人检验规范 → 查找依据和关系 → 形成处理建议 → 返回原业务办理预览 → 人工确认 → 原单据回查。实时业务事实由 MES 提供，SOP 只提供操作依据，AI 不能代填实际测量结果。

Dify 是教师提到的加分方向，本轮没有部署或验证 Dify，不能把上述设计写成已运行的 Dify 工作流。后续采用时还需核对资源、凭据边界、实际运行及其许可证附加条件。

## 可展示的解决过程

| 问题 | 处理 | 验证 |
|---|---|---|
| 图抽取失败拖累全部问答 | 文档向量与云建图分开 | 图失败时本地文档仍可答原文 |
| 更新失败让旧资料也不能问 | 候选/已发布版本分开 | 旧版继续使用，新版成功后事务切换 |
| 同编号前后缀把图拆开 | 领域提示与保守编号规范化 | 三跳实际存在，边仍有原文 |
| 删除后召回相近型号 | 最终编号与来源校验 | 已删除目标明确无依据 |
| 重复初始化导致死锁 | 全程初始化锁、schema 快路 | 真实 PG 回归及 80 例重跑 |
| 撤销同意与在途外发竞态 | 授权覆盖请求发送，区分 CONNECT 与 POST | 真实回环 HTTP 和协议链路检查 |
| 重复图抽取消耗额度 | 只复用模型配置相同且仍有效来源的抽取缓存 | 20/20 时仍能 0 外部调用重建未变资料 |
| 相同片段的多个来源互相影响 | 保留全部有效引用台账、重新指定缓存归属 | 连续删除共享来源回归 |
