# 台灯 MES 界面约定

默认主题为“晴空米白”：以米白和暖白构成大部分页面，天蓝色仅用于主操作、选中项和必要的数据强调，正文采用中性深灰。

- 页面背景 `#f7f5ee`，内容表面 `#fffefa`，主操作色 `#176fa7`。
- 所有公共配色与几何尺寸由 `workspace/vscode/ems-forword/src/styles/tokens.css` 维护；公共表格、表单、弹窗、焦点与减少动态效果由 `base.css` 维护。
- 业务页按标题、操作、筛选、数据、明细组织；重点操作靠近当前对象。状态保留文字和语义色，不单靠颜色区分。
- AI 工作台保留业务问答、会话与固定输入区；任务说明和示例完整换行，更多示例按需展开，短屏内的消息和能力区可滚动。手机页头分行排列，操作区域至少 44px。界面优化不改变 AI 能力、权限、执行预览和确认流程。
- 左侧快捷办理位于会话记录之前；正式会话按后端目录显示入口，加载失败提供重新加载。开发预览沿用同一业务顺序展示禁用入口，不假设账号权限，也不查询远端会话历史；“连接并登录”直接打开登录页，无需先退出预览。
- 待办区分开发预览、首次加载、连接失败、实际为空和已有结果；刷新失败保留上次数据并提供重试，不把未取得的数据解释为零条待办。
- PC 与手机共享组件；手机导航初次渲染即使用抽屉，表格在自身容器中横向滚动，表单抽屉适应屏幕宽度。
- 登录页与生产大屏共享米白背景和中性深灰文字。大屏以 KPI、产线状态、排程、关注事项和七日统计组织信息，移除发光边框与装饰网格，语义色只承担状态与数据编码。
- 大屏保留 1920×1080 等比画布；窄屏增加不随画布缩小的返回工具栏，横竖屏均保留返回路径。排期总览支持 Enter / Space 展开、Tab 循环、Esc 关闭并恢复原焦点；超过显示范围的产线通过放大总览查看。
- 统计指标使用实际取得的数据；用“待排生产订单”替换原先固定为零的逾期计划读数。开发预览不注入生产实绩，验收中的演示数据仅在临时浏览器会话中使用并明确标记。
- `branding.js` 集中维护“智能调光台灯 MES / 台灯 MES”，浏览器标题跟随相同名称。存储隔离标识不决定产品名称。

本轮研究参考的是公开系统界面的布局与操作组织，没有并入参考项目源码或品牌素材。后续调整继续使用现有变量，避免页面各自叠加独立配色。

界面精修与快捷入口验证：82 项前端测试通过、生产构建通过；检查开发预览的首页、AI 工作台、订单、1920px 大屏，以及 1024px 平板、390px 手机和大屏横屏预览。另以临时演示数据检查五条产线、七项排期、设备状态、质量、生产趋势和排期放大；检查结果不代表实际经营数据。独立本机验证库上的正式登录和快捷表单已联调，未执行单据预览确认、重跑完整业务回归或请求真实模型。
