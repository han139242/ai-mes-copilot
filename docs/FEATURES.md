# AI 能力：业务办理、私有知识与图谱

简体中文 · [English](FEATURES.en.md) · [项目首页](../README.md)

AI-MES Copilot 把自然语言转成已注册的业务能力，再由原有领域服务执行。模型负责理解意图与组织计划；库存计算、状态迁移、权限检查和数据写入由业务代码完成。

数据流和代码入口见[AI 架构](AI_ARCHITECTURE.md)，操作见[教师演示](TEACHER_DEMO.md)。下列 39 项为业务目录，私有知识能力另列。

## 私有知识与研判

| 能力 | 当前行为 |
|---|---|
| 五格式文件管理 | PDF、DOCX、XLSX、TXT、MD 上传、更新、下载、删除；版本、原件哈希与位置可追溯 |
| 文档 RAG | 本地 512 维中文嵌入与 pgvector 检索，按完整编号、问题关注的证据类型和来源覆盖排序。多编号对比证据不足时展示已有原文与缺失编号 |
| GraphRAG / 融合 | LightRAG 抽取关系、AGE 存图；自动、文档、图谱、融合显示实际路径与降级原因 |
| 图谱探索 | 实际节点和边、搜索、类型筛选、缩放、相邻展开、当前图六段以内路径、原文与文字列表 |
| 私有会话与偏好 | 每用户独立数据库、角色和目录，历史及岗位/熟悉程度/篇幅偏好；偏好不扩大权限 |
| 研判工作单 | 从本人历史保存答复与依据，人工备注/核对项、编辑冲突保护、原文导出与转业务前来源复核 |
| 业务衔接 | 实时问题可转交原话，知识与工作单只形成业务草稿，执行保留原确认流程 |

索引使用候选版本发布与异步任务；图失败时已就绪文档仍可检索。未配置模型、未同意处理或缺少依据时不会冒充已生成。引用检查覆盖来源有效性和编号，不能证明逐句语义正确。

本地人脸认证与原账号/JWT衔接，支持本人管理和管理员授权重置，真人验收范围见[认证说明](FACE_AUTO_CAPTURE.md)。

## 一次办理的过程

1. 用户描述目标，AI 识别业务对象、参数和所需能力。
2. 系统读取真实单据，核查权限与前置条件；信息缺失时展示候选并继续询问。
3. 页面展示办理预览，用户确认后执行。
4. 领域服务检查事务、库存、状态和重复请求，记录执行结果。
5. 助手回查业务结果，并给出可继续办理的下一步。

多步任务遇到阻断时，显示已完成步骤与失败原因，按实际状态继续处理。自动化规则在配置的授权范围内按事件或定时执行。

## 对话衔接

带否定、更正和复合目标的请求优先进行语义判断，保留“只查”“先别下达”等限制条件。悬浮助手可以携带当前页面路径及链接中明确的业务编码；同一请求失败后重试会保留原对象线索。模型仍需核对真实单据，并在需要时澄清必填信息。改进范围与案例见[对话理解记录](AI_USABILITY.md)。

## 质量与事实边界

逐件检验的物理测量和实测值录入由质检人员完成。提交检验结果使用已录入的数据；AI 不生成虚构测量值。模型不直接执行任意 SQL，也不以用户口头声明替代单据状态、库存和检验结果。

排程推演读取业务快照并比较方案，不将假设方案写入正式排程；生产计划的实际生效通过正式办理流程完成。
