# AI 业务能力

AI-MES Copilot 把自然语言转成已注册的业务能力，再由原有领域服务执行。模型负责理解意图与组织计划；库存计算、状态迁移、权限检查和数据写入由业务代码完成。

## 查询与分析

当前目录共 20 项：库存收发存、库存现有量、安全库存缺口、工单详情、开工条件核查、开工处置方案、日产量与不良、不良分析、批次追溯、排程与产能、订单进度、订单排程推演、设备故障影响、追加产能测算、BOM 用量、质量良率、工单列表、客户订单、待检清单和通用业务数据查询。

## 直接办理

当前目录共 19 项：创建生产订单、安排生产订单、生成工单、下达工单、生成派工单、下达派工单、开工工序任务、提交报工、开始生产、生成领料单、领料转线边、确认出库、确认入库、提交已有检验结果、生成成品入库单、生成销售出库单、生成出货检验单、确认发货、审核报工。

能力定义以 `workspace/idea/ems/src/main/java/com/neuedu/ems/service/ai/AiCapabilityCatalog.java` 为准。资源查询范围由 `AiDataResourceCatalog` 和当前账号权限共同约束。

## 一次办理的过程

1. 用户描述目标，AI 识别业务对象、参数和所需能力。
2. 系统读取真实单据，核查权限与前置条件；信息缺失时展示候选并继续询问。
3. 页面展示办理预览，用户确认后执行。
4. 领域服务检查事务、库存、状态和重复请求，记录执行结果。
5. 助手回查业务结果，并给出可继续办理的下一步。

多步任务遇到阻断时，显示已完成步骤与失败原因，按实际状态继续处理。自动化规则在配置的授权范围内按事件或定时执行。

## 质量与事实边界

逐件检验的物理测量和实测值录入由质检人员完成。提交检验结果使用已录入的数据；AI 不生成虚构测量值。模型不直接执行任意 SQL，也不以用户口头声明替代单据状态、库存和检验结果。

排程推演读取业务快照并比较方案，不将假设方案写入正式排程；生产计划的实际生效通过正式办理流程完成。
