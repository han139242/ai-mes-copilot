## 本轮修复

1. **上传后等待空库扫描。** 从每3秒逐库串行检查，改为变更成功后优先唤醒当前用户；30秒发现循环保留丢失通知和重启恢复。单库故障不会中断其他用户。
2. **取消后仍发布向量。** 在同一用户锁内校验任务状态、尝试代际和资料修订，再替换向量/有效版本；立即重试也不会被旧尝试覆盖。
3. **恢复误伤活跃任务。** 整轮索引持有跨进程PostgreSQL租约；恢复只处理无活跃租约的旧任务。图谱发布、异常收尾和SDK子进程后续模型发送也核对尝试代际。
4. **迟到来源重开旧面板。** 新会话、历史会话、来源关闭、删除及卸载统一使旧预览失效，清空加载和错误状态。
5. **图谱还原不完整。** 还原或清空搜索会重新请求完整授权图；最新请求胜出，旧筛选迟到不能覆盖还原结果。
6. **启动和说明不一致。** 启动器检查数据库端口，新增贯穿子进程的`-NoCloud`；更正免用户名登录说明、解析器依赖名称和过时的20次限制说明。
