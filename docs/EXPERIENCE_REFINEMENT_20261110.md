# 私有知识体验完善与原生存储验收

日期：2026-11-10。原 MES 的生产、库存、质量、权限、快捷办理及人脸入口保留；本轮围绕“得到答复以后，用户怎样核对、保存和继续处理”完善交互。

## 本轮可以直接使用的能力

### 带来源的研判工作单

资料答复下的“存为工作单”保存本人这条历史问答的原问题、答复及来源，随后可以补充人工核对项、现场备注和标题。工作单保存在当前用户自己的 PostgreSQL 数据库中，换账号不会带走内容。

- 原答复和引用保持只读，人工修改与资料事实分开。
- 保存、撤销未保存修改、刷新和删除有明确状态。并发修改用版本校验，冲突或断线保留当前草稿，并提供本机草稿导出。
- 普通离页会保护未保存内容；退出或身份变化立即清理私有草稿，旧请求不能重新发布旧账号内容。
- 导出交接稿包含人工勾选状态、原文摘录、文件版本、SHA-256 和定位。
- 每次导出或转交业务前重新核对来源。资料已更新、删除或失效时，工作单标记“需重新核对”，阻止转业务；仍可导出有明确过期说明的原记录。
- 转业务只填入原工作台草稿，保留来源和“待本人确认”。按原接口的500个UTF-16单位预算压缩长内容，明确提示完整备注保留在工作单中，并保护emoji字符边界。

这条链路适合演示 L100 的 DRV-07 生效配置与 DRV-08 候选变更：先核对依据，再列现场事项，最后交接或回到原业务确认。人工勾选不代表工程变更已批准、检验合格或单据已执行。

### 阅读与探索

答复支持标题、段落、列表、编号步骤、表格和代码的安全文本渲染；不执行模型返回的HTML。关键引用可以直接打开同一版本原文；来源区先显示答复实际引用的依据，更多来源按需展开。取消未保存草稿的离页时，浏览器标题保留当前页面，避免与实际路由错位。

欢迎区收敛为三个能填入问题的任务入口。空会话返回时滚动归零，非空历史和新消息滚到最新内容。390×844与470×668下，输入和44px发送按钮保持在屏内；工作单在手机上使用正常长阅读。

图谱概览保留真实节点与关系，低缩放时展示小节点及少量名称，通过悬停提示、选中详情、搜索、文字列表和缩放进一步查看。产品、选中项和精确搜索对象可显名；放大后恢复详细标签，有序关联路径继续保留。真实缩放值控制标签层级，四舍五入的百分比只用于显示。

### 无本地模型次数上限

维护者本轮明确取消验证20次限制。系统和验证脚本的默认0表示无限，持久调用记录保留；本轮记录从40增加到45。旧任务已签署的有限授权仍保留自己的上限，独立部署者仍可主动配置正数限额。资料外发同意、原业务权限及模型平台额度继续有效。

## 私有数据库迁移与清理边界

原Windows绑定目录在停止后进行离线复制。完整清单包含184004个文件、532个目录和508个数据库目录；归档逐文件校验，目标完整SHA-256、文件/目录集合及源文件复查通过，独立census补充遇错即停和reparse拒绝。原实例使用immediate停止，新实例保留WAL并完成恢复；没有关闭fsync或省略恢复文件。

正式数据位于Docker原生命名卷`mes-stage2-private-pgdata-native-20261110`，Docker虚拟磁盘仍在D盘。首次约39.96秒进入healthy，随后正常重启约7.05秒恢复healthy。原12份资料、文件哈希和本人128维模板再次核对未变，持久调用记录为45、无本地次数上限。

Compose要求显式指定已创建/迁移核验的外部命名卷，缺失配置时停止；初始化脚本拒绝覆盖现有凭据和资料。正式`postgres-volume.json`是数据定位记录，应与原配置一起保留。

已删除经授权的旧`postgres`物理副本与`migration-work-20261110`临时目录，共10768525398字节，约10.03GiB；删除前核对所有容器均不再绑定旧目录，并检查解析后的绝对路径和reparse边界。正式数据、密钥、模型、环境与验收证据保留。实际删除清单记录在本机`migration-cleanup.json`。
