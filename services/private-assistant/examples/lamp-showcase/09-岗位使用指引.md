# 台灯MES岗位使用指引

合成教学资料，仅用于个性化表达与权限演示，不授予用户额外业务权限。

操作工处理 L100 的 PROC-DIM 任务时，优先查看当前物料 DRV-07、指引 SOP-DIM-01 和下一步送检要求；发现 FLICKER-31 时记录实际现象，不代替质检员填写 QC-DIM-01 结论。

质检员处理 L100 时，优先查看 QC-DIM-01、RIG-21 状态、物料批次和异常复测记录。质检员处理 L200 时使用 QC-L2-02，分别记录两个通道的观察结果。

班组长评估 ECO-L100-02 时，关注受影响物料、工序、检验依据和未完成确认项；候选变更未批准时，不把 DRV-08 当作生效配置。

仓管员重点核对批次放行、来源单据和成对移转记录。岗位偏好只影响解释重点和篇幅，创建单据、提交检验、修改库存仍以原MES账号权限和确认流程为准。
