# 台灯知识演示资料

本目录提供10份相互关联的合成教学资料。所有编号、配置、步骤与关系均为演示设计，不是国家、行业或企业正式标准，不用于真实生产、检验或维修。

## 这套资料展示什么

- L100与L200有不同物料、工序、检验规范和工位，不能相互套用。
- L100可沿`DRV-07 → PROC-DIM → QC-DIM-01 → RIG-21`核对装配和检验依据。
- FLICKER-31与ERR-CH-02分别对应两个型号的异常追溯。
- ECO-L100-02明确为未批准候选变更；DRV-08不能被回答为当前生效配置。
- 资料没有提供实时库存或色温误差限值。前者应转原MES查询，后者应说明缺少依据。

每份文件对应一个主题：产品、物料表、装配、检验、故障、设备、仓储、变更、岗位和交接。Markdown为公开可审阅源稿；构建工具可输出6份MD、1份XLSX、1份DOCX、1份PDF和1份TXT。

## 构建与验收

在仓库根目录，用已有的Python文档环境运行`services/private-assistant/scripts/build_showcase.py --output <新空目录>`。需要python-docx和reportlab，以及`--font`指定的现有中文TrueType字体；不提供表格运行时则BOM保留Markdown。五格式版另提供`--node <Node路径> --packages <包含@oai/artifact-tool的node_modules路径>`。工具拒绝覆盖非空输出目录，生成manifest记录源稿和实际文件SHA-256。

使用独立私有服务环境运行：

```powershell
. .\scripts\load-stage2-environment.ps1 -NoCloud
$env:PYTHONPATH=(Join-Path (Get-Location) 'services\private-assistant')
& 'D:\AI-MES-Stage2\.venv\Scripts\python.exe' .\services\private-assistant\scripts\verify_showcase.py --bundle '<构建输出目录>' --output '<本轮证据目录>'
```

验证器只创建独立合成用户，使用本地真实向量，检查10份文件逐字节下载、24个问题的关键事实/出处、来源逐项回读及另一用户的访问隔离；它不代表生成准确率。题目及预期位于[questions.json](questions.json)。

真实建图/生成须明确授权。`activate_showcase.py`只支持预置`lamp_quality`演示账号，须先经MES登录和私有知识权限检查，且目标库必须为空或仅包含本套完全相同的文件。必须显式传`--allow-model`；2026-11-10起按维护者要求，`--max-new-calls`默认0表示不设本地次数上限，正整数可选，不再固定最多20次。每个上传任务在提交前签名绑定完整来源清单和调用策略，后台接手仍验证；部分导入不外发。旧的有限授权任务不被重跑扩大。原持久调用记录保留，仍受模型平台的余额、限流和资料处理同意约束；不支持替换其他原件、清空文件、修改本人模板或绕过MES权限。

## 推荐展示顺序

1. 登录“质检员”演示账号，打开“我的知识”，展示10份资料及五种格式；管理员原库作为另一用户的隔离对照。
2. 提问“L100当前生效的驱动板是什么”，打开引用，核对文件、版本与原文位置。
3. 选择融合，提问“L100的驱动板、装配工序和检验规范怎样关联”，查看多个原文来源和实际关系线索。
4. 图谱中搜索L100，展开关系，打开节点/边来源，再还原完整图谱。
5. 提问“ECO-L100-02批准了吗，现在能换DRV-08吗”，核对“未批准”和“当前DRV-07”两个条件。
6. 提问“L100的色温误差合格限值是多少”，核对系统没有补造阈值；查询实时库存应转原业务助手。
7. 用单独临时文件演示上传、更新、下载和删除，不覆盖这套基线。切换账号，核对目录与历史隔离。
