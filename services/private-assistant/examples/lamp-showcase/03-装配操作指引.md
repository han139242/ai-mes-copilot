# 调光台灯装配操作指引

合成教学资料，仅用于MES演示，不是实际带电作业规程。现场操作必须由有资质人员依据正式规程执行。

## 接线工序

L100 的接线工序 PROC-WIRE 使用 LED-10 灯板和 ADP-12 适配器。作业前先按正式规程确认安全隔离和物料标识；发现接线标识不清、零件损伤或不匹配时，停止流转并登记异常，不自行推断接法。

## 调光装配

L100 的调光装配工序 PROC-DIM 使用 DRV-07 驱动板和 MAT-BASE-10 底座。PROC-DIM 的教学指引编号为 SOP-DIM-01；该工序完成后送检 QC-DIM-01，使用演示测试工位 RIG-21。

PROC-DIM 的工单完成不能代替 QC-DIM-01 检验放行。操作工提交实际作业记录；质检员记录实际观察结果，不能由AI编造测量值或自动填合格。

## 包装与型号区分

L100 的包装工序 PROC-PACK 使用 MAT-BOX-10，包装前核对整机标识和已完成的检验记录。L200 走 PROC-L2 和 QC-L2-02，不直接沿用 L100 的装配与检验结论。
