# 台灯产品型号说明

合成教学资料，仅用于MES功能演示，不是国家、行业或企业正式标准，不用于真实产品判定。

## 当前产品

L100 是基础调光台灯。L100 当前使用 DRV-07 驱动板、LED-10 灯板和 ADP-12 电源适配器；整机装配包含接线工序 PROC-WIRE、调光装配工序 PROC-DIM 和包装工序 PROC-PACK。

L100 的调光检验依据为 QC-DIM-01，示例检验码为 SKY-731。L100 的演示检验在低、中、高三个亮度档位逐项记录观察结果，不能用默认值代替实际记录。

L200 是双通道演示台灯。L200 使用 DRV-09 驱动板、LED-20 灯板和 ADP-24 电源适配器；采用装配工序 PROC-L2 和检验规范 QC-L2-02。L200 的示例检验码为 CLOUD-928。

## 型号与变更边界

L100 与 L200 的驱动板、适配器和检验规范不能互相套用。DRV-08 是 L100 的候选替代板，仍处于 ECO-L100-02 待评审状态；当前生效配置仍为 DRV-07，不得把候选板当作已批准配置。
