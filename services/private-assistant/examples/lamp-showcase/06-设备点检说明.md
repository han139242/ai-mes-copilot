# 演示设备点检说明

合成教学资料，仅用于MES演示，不是设备维护规程或真实校准证书。

RIG-21 是 L100 调光检验演示工位，服务于 PROC-DIM 和 QC-DIM-01。RIG-21 每次使用前的教学点检包括：核对工位标识、检查外观、确认记录入口可用，以及核对有效状态标识；实际安全检查按正式规程执行。

RIG-21 的点检记录缺失、有效状态不明或存在未关闭异常时，先交设备管理员核查，不自行假定工位可用。FLICKER-31 的检验复测需要确认 RIG-21 状态，不能把工位异常直接归因于产品。

RIG-22 是 L200 双通道演示工位，对应 PROC-L2 和 QC-L2-02。RIG-22 应分别记录两个通道的观察情况。

本文不含 RIG-21 或 RIG-22 此刻是否在线、当前故障数、校准到期日等实时数据。需要这些信息时转到MES业务助手查询。
